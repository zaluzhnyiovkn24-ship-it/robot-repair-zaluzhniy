# Фізичний паспорт рівня

Для кожного об'єкта рівня: яке в нього фізичне тіло, який колайдер і як він поводиться при зіткненні.

| Об'єкт | Rigidbody2D | Колайдер | Як поводиться |
|---|---|---|---|
| Робот (PlayerCharacter) | Dynamic, Gravity Scale 0, Freeze Rotation Z | Box Collider 2D лише на ногах (0.55 × 0.5, зміщений вгору на 0.28) | Рухається через `MovePosition` у `FixedUpdate`, упирається в воду, ящики, дерева. Не обертається боком |
| Тайлмап (Grid/Tilemap) | Static | Tilemap Collider 2D + Composite Collider 2D (Merge) | Один суцільний контур замість сотні квадратів, без «швів» між плитками |
| Плитки підлоги, майданчик, дорога | — | Collider Type = None | Прохідні: колайдер не потрібен, по них можна ходити |
| Плитки води (озера) | — | Collider Type = Grid | Непрохідні: робот упирається в берег |
| Ящики (Crate) | Немає (статичний колайдер) | Box Collider 2D ≈ 65% ширини, пів висоти | Нерухомі перешкоди, ззаду/спереду сортуються за Y |
| Кущі (Bush) | Немає | Box Collider 2D ≈ 65% ширини, пів висоти | Перешкода по низу куща |
| Дерева (PineTree, GreenTree, TwistedTree) | Немає | Box Collider 2D лише на стовбурі | Крона не блокує: робот заходить за дерево і виходить перед ним |
| DamageZone | Немає | Box Collider 2D | Зона-пастка (Draw Mode Tiled, Adaptive). Перекриває північну дорогу, змушує обходити |

## Сортування
Renderer 2D: Transparency Sort Mode = Custom Axis (0, 1, 0). Усі декорації мають Pivot = Bottom, у робота Pivot (0.5, 0) і Sprite Sort Point = Pivot. Тому об'єкт, що нижче по екрану, малюється поверх того, що вище.

## Що змінилося проти плану
Крони дерев спершу мали колайдер, і робот не міг зайти за дерево; залишив колайдер лише на стовбурі.
